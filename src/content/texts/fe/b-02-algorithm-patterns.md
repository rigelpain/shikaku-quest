## この分野の位置づけ
科目Bの擬似言語16問は、出題されるアルゴリズムの型がある程度決まっています。型を知っていれば「何をしているか」の見当がついた状態でトレースでき、読解の時間を大きく減らせます。

## 要点
- 線形探索は先頭から順に比較し、見つかったら添字を返して終了、見つからなければ −1 や「未定義」を返す形が定番です。
- 2分探索は low・high・mid の3変数で範囲を半分に狭めます。mid ← (low + high) ÷ 2 と、見つからなかったときの low > high の終了条件が肝です。
- 整列はバブルソート（隣接交換）、選択ソート（最小値を先頭へ）、挿入ソートが出ます。二重ループの内側の範囲と、交換に使う一時変数の動きを追います。
- 再帰は「終了条件 → 自分より小さい問題を呼ぶ → 結果を組み合わせる」の順で読み、呼出しの深さごとに局所変数の表を分けて書きます。
- スタックは push と pop、キューは enqueue と dequeue の操作列を順にたどり、最終的に残る要素を答えます。
- 文字列処理では、1文字ずつ取り出して条件判定し、カウントや置換を行います。文字の位置と「1 始まり」の添字に注意します。

## 頻出用語
- **番兵** — 探索の終了判定を簡単にするため末尾に置く目印の値。
- **2分探索** — 整列済み配列の中央と比較し範囲を半減させる探索。
- **バブルソート** — 隣り合う要素を比較して交換を繰り返す整列。
- **選択ソート** — 未整列部分の最小値を選んで先頭と交換する整列。
- **再帰** — 関数が自分自身を呼び出す構造。階乗、フィボナッチ、最大公約数が典型。
- **ユークリッドの互除法** — gcd(a, b) = gcd(b, a mod b) で最大公約数を求める方法。
- **スタック** — 最後に入れた要素を最初に取り出す構造。push/pop。
- **キュー** — 最初に入れた要素を最初に取り出す構造。enqueue/dequeue。
- **スワップ** — 2つの変数の値を一時変数を介して交換する操作。

## よくある引っかけ
- スワップは tmp ← a[i]、a[i] ← a[j]、a[j] ← tmp の3行が必要です。2行で書いた選択肢は値が消えます。
- 2分探索で見つからなかった場合の更新は low ← mid + 1、high ← mid − 1 です。±1 を忘れると無限ループになります。
- 再帰の戻り値を使う式（n × fact(n − 1)）は、最も深い呼出しから順に値が確定します。表は内側から埋めます。
- バブルソートの内側ループの上限が「n − i」なのか「n − 1」なのかで、比較回数と答えが変わります。

2分探索の中核部分を示します。

```text
○整数型: search(整数型の配列: a, 整数型: key)
  整数型: low ← 1
  整数型: high ← a の要素数
  整数型: mid
  while (low ≦ high)
    mid ← (low + high) ÷ 2
    if (a[mid] = key)
      return mid
    elseif (a[mid] < key)
      low ← mid + 1
    else
      high ← mid − 1
    endif
  endwhile
  return -1
```

a = {2, 5, 8, 12, 16}、key = 12 なら、mid は 3 → 4 と動き、2回目の比較で見つかります。

## 確認クイズ
Q1. gcd(48, 18) をユークリッドの互除法で求めるとき、途中の (a, b) はどう変化しますか。
→ 答え：(48, 18) → (18, 12) → (12, 6) → (6, 0) で答えは 6（a mod b を繰り返し、b が 0 になった時点の a が答えのため）。

Q2. 要素数 n の配列をバブルソートで整列するとき、比較回数の最大はおよそ何回ですか。
→ 答え：n(n − 1) ÷ 2 回（外側ループ i 回目に n − i 回の比較を行い、その合計になるため）。

Q3. 空のスタックに push(1)、push(2)、pop()、push(3)、pop() を順に行った後、スタックに残る要素は何ですか。
→ 答え：1（2 と 3 が pop で取り出され、最初に入れた 1 だけが残るため）。
