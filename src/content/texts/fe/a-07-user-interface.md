## この分野の位置づけ
画面設計、入力チェック、アクセシビリティ、UX の原則を扱います。出題数は1〜2問と少なめですが、覚えれば確実に得点できる分野で、情報メディアやシステム開発技術（外部設計）と内容が重なります。

## 要点
- GUI 部品はラジオボタン（排他選択）、チェックボックス（複数選択）、ドロップダウンリスト（省スペース）など、目的に応じて使い分けます。
- 入力チェックには形式チェック、範囲チェック、桁数チェック、照合チェック、チェックディジットがあります。
- ユーザビリティは「有効さ・効率・満足度」で定義され、使いやすさの度合いを表します。
- アクセシビリティは障害の有無や年齢に関係なく利用できることで、代替テキストやキーボード操作対応が代表例です。
- ユニバーサルデザインは最初から誰にでも使える設計を目指す考え方です。
- 画面設計ではエラーメッセージを具体的にし、入力項目の順序を業務の流れに合わせ、操作を取り消せるようにします。
- ヒューマンインタフェースの評価にはヒューリスティック評価、ユーザーテスト、アンケートが使われます。
- Web では WCAG や JIS X 8341 がアクセシビリティの指針として参照されます。

## 頻出用語
- **ユーザビリティ** — 特定の利用者が目的を有効・効率的・満足に達成できる度合い。
- **アクセシビリティ** — 身体状況や環境を問わず情報や機能にアクセスできること。
- **ユニバーサルデザイン** — 誰でも使えるよう最初から設計する考え方。
- **アフォーダンス** — 物の形状や見た目が使い方を示唆する性質。
- **ラジオボタン** — 複数の選択肢から1つだけ選ぶ部品。
- **チェックボックス** — 複数の選択肢から任意の数を選ぶ部品。
- **プルダウンメニュー** — クリックで選択肢を展開するメニュー。
- **チェックディジット** — 入力誤りを検出するために付加する検査用の数字。
- **ニューメリックチェック** — 数値項目に数字以外が入っていないか確認する入力チェック。
- **ヒューリスティック評価** — 専門家が経験則に基づき UI の問題を洗い出す方法。
- **プロトタイプ** — 設計段階で作る試作画面。利用者の確認に使う。
- **ジェスチャインタフェース** — タッチやスワイプなど身振りで操作する方式。
- **音声認識** — 音声を文字や命令に変換する入力方式。

## よくある引っかけ
- ユーザビリティとアクセシビリティは別物です。前者は「使いやすさ」、後者は「利用できること」が焦点です。
- ラジオボタンは「1つだけ」、チェックボックスは「複数可」です。選択肢が多いときはドロップダウンが適します。
- チェックディジットは誤りを「検出」する仕組みで、「訂正」はできません。
- ユニバーサルデザインはバリアフリーと違い、後から障壁を取り除くのではなく最初から誰でも使える設計を目指します。
- エラーメッセージは「エラーです」ではなく「郵便番号は7桁の数字で入力してください」のように修正方法を示すのが良い設計です。

## 確認クイズ
Q1. 商品コードの末尾に付けて入力ミスを検出する数字を何といいますか。
→ 答え：チェックディジット（コードから計算した値と照合して誤りを検出するため）。

Q2. 性別のように選択肢から必ず1つだけ選ばせたいとき、適した GUI 部品は何ですか。
→ 答え：ラジオボタン（排他的な選択に使う部品だから）。

Q3. 画像に代替テキストを付ける目的は、主にどの概念の向上ですか。
→ 答え：アクセシビリティ（画面を見られない利用者も内容を把握できるようにするため）。
