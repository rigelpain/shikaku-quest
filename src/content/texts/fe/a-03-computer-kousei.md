## この分野の位置づけ
CPU・メモリ・入出力装置といったコンピュータ本体の仕組みを扱い、科目Aでは計算問題（命令実行時間、キャッシュのヒット率）が定番です。基礎理論の2進数と、システム構成要素の性能評価につながります。

## 要点
- CPU は命令の取出し（フェッチ）→解読（デコード）→実行→書戻しを繰り返します。プログラムカウンタが次の命令の番地を指します。
- クロック周波数が 1GHz なら1クロックは 1ns です。命令あたり平均クロック数（CPI）が分かれば実行時間を計算できます。
- MIPS は1秒間に実行できる命令数（百万単位）です。1命令平均2クロックで 1GHz なら 500MIPS です。
- パイプラインは命令の各段階を重ねて処理し、スループットを上げます。分岐で乱れるのがハザードです。
- 記憶階層はレジスタ > キャッシュ > 主記憶 > 補助記憶の順に速く、容量は逆に小さくなります。
- キャッシュの実効アクセス時間は「ヒット率×キャッシュ時間 + (1−ヒット率)×主記憶時間」です。
- メモリインタリーブや DMA は主記憶や入出力を高速化する仕組みです。
- 補助記憶では SSD（フラッシュメモリ）と HDD の特徴、RAID との関係を押さえます。
- 入出力インタフェースは USB、HDMI、Bluetooth などの用途と特徴が問われます。

## 頻出用語
- **プログラムカウンタ** — 次に実行する命令の番地を保持するレジスタ。
- **CPI** — 1命令あたりに必要な平均クロック数。
- **MIPS** — 1秒あたり百万命令単位の実行性能。
- **パイプライン** — 命令処理の段階を重ねて並列に進める方式。
- **スーパースカラ** — 複数のパイプラインで同時に複数命令を実行する方式。
- **マルチコア** — 1つの CPU に複数の演算コアを持つ構成。
- **キャッシュメモリ** — CPU と主記憶の速度差を埋める小容量高速メモリ。
- **ヒット率** — 必要なデータがキャッシュにある確率。
- **ライトバック／ライトスルー** — キャッシュ更新時に主記憶へ書く時期の違い。ライトスルーは同時に書く。
- **DMA** — CPU を介さず入出力装置と主記憶が直接データ転送する方式。
- **割込み** — 実行中の処理を中断して別の処理に移る仕組み。
- **DRAM／SRAM** — DRAM はリフレッシュが必要で主記憶向き、SRAM は高速でキャッシュ向き。
- **フラッシュメモリ** — 電源を切っても消えない書換え可能なメモリ。SSD や USB メモリに使う。

## よくある引っかけ
- クロック周波数が同じでも CPI が違えば性能は違います。周波数だけで速さを判断しないことです。
- 1GHz = 10^9 Hz、1ns = 10^-9 秒です。単位の接頭語（M、G、n、μ）の換算ミスが最多の失点源です。
- キャッシュのヒット率が高いほど実効時間は短くなります。ミス率を使う式と取り違えないようにします。
- SRAM と DRAM は「速いのが SRAM、安くて大容量が DRAM」です。名前の S を「主記憶」と誤解しがちです。
- 揮発性メモリ（RAM）と不揮発性メモリ（ROM、フラッシュ）の区別を確認しましょう。

数値例：キャッシュ 10ns、主記憶 100ns、ヒット率 0.9 のとき、実効アクセス時間は 0.9×10 + 0.1×100 = 19ns です。

## 確認クイズ
Q1. クロック周波数 2GHz、CPI が 4 の CPU の性能は何 MIPS ですか。
→ 答え：500MIPS（2×10^9 ÷ 4 = 5×10^8 命令/秒だから）。

Q2. キャッシュへの書込み時に主記憶にも同時に書く方式を何と呼びますか。
→ 答え：ライトスルー（主記憶との一貫性を常に保つ代わりに書込みが遅い方式のため）。

Q3. CPU を介さずに入出力装置が主記憶と直接データをやり取りする仕組みは何ですか。
→ 答え：DMA（CPU の負荷を減らして転送を高速化するため）。
