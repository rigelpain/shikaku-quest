## この分野の位置づけ
科目Aで毎回3〜4問出る主要分野で、セキュリティとも強く関係します。OSI 参照モデルや TCP/IP の階層、IP アドレスの計算、各種プロトコルの役割が中心です。

## 要点
- OSI 参照モデルは物理・データリンク・ネットワーク・トランスポート・セッション・プレゼンテーション・アプリケーションの7層です。
- TCP/IP ではイーサネット（データリンク）、IP（ネットワーク）、TCP/UDP（トランスポート）、HTTP など（アプリケーション）の4階層で考えます。
- IPv4 アドレスは 32ビットで、サブネットマスクによりネットワーク部とホスト部に分かれます。ホスト数は 2^(ホスト部ビット数) − 2 です。
- TCP はコネクション型で信頼性を保証し、UDP はコネクションレスで高速・軽量です。
- 主なポート番号：HTTP 80、HTTPS 443、SMTP 25、POP3 110、IMAP 143、DNS 53、SSH 22。
- DNS は名前と IP の変換、DHCP は IP の自動割当て、NAT/NAPT はプライベート IP とグローバル IP の変換です。
- リピータ／ハブは物理層、ブリッジ／スイッチはデータリンク層、ルータはネットワーク層で動作します。
- 伝送時間 = データ量 ÷ 実効伝送速度です。伝送効率が与えられたら速度に掛けます。
- IPv6 は 128ビットで、アドレス枯渇の解決策です。無線 LAN は IEEE 802.11 系の規格です。

## 頻出用語
- **MAC アドレス** — ネットワーク機器固有の 48ビットの識別子。データリンク層で使う。
- **IP アドレス** — ネットワーク上の機器を識別する論理アドレス。
- **サブネットマスク** — IP アドレスのネットワーク部を示すビット列。
- **デフォルトゲートウェイ** — 他ネットワーク宛の通信を最初に送るルータ。
- **ARP** — IP アドレスから MAC アドレスを求めるプロトコル。
- **DHCP** — IP アドレスなどの設定を自動で配布する仕組み。
- **DNS** — ドメイン名と IP アドレスを対応づけるサービス。
- **NAPT** — ポート番号も使って複数の端末で1つのグローバル IP を共有する変換。
- **TCP** — 3ウェイハンドシェイクで接続し、再送で信頼性を確保するプロトコル。
- **UDP** — 確認応答なしで送るプロトコル。音声や動画の配信向き。
- **ルータ** — IP アドレスを基に経路を選んで転送する機器。
- **スイッチ** — MAC アドレスを学習して必要なポートだけに転送する機器。
- **CSMA/CD** — 衝突を検知して再送する有線 LAN のアクセス制御方式。
- **SMTP／POP3／IMAP** — メール送信／受信（ダウンロード）／受信（サーバ上で管理）。

## よくある引っかけ
- /24 のネットワークで使えるホスト数は 256 ではなく 254 です。ネットワークアドレスとブロードキャストアドレスを除きます。
- 伝送速度の bps は「ビット」、ファイルサイズの B は「バイト」です。8倍の換算を忘れると答えが8倍ずれます。
- ルータは「ネットワーク層」、スイッチは「データリンク層」です。「どちらも転送する」では区別できません。
- SMTP は送信、POP3/IMAP は受信です。IMAP はサーバにメールを残すので複数端末で同期しやすいです。
- プライベート IP アドレス（10.x、172.16〜31.x、192.168.x）はインターネットでは直接使えません。

数値例：10MB のファイルを 100Mbps・伝送効率 80% の回線で送ると、10×8 = 80M ビット ÷ (100M×0.8) = 1秒です。

## 確認クイズ
Q1. サブネットマスクが 255.255.255.192 のとき、1サブネットで使えるホスト数はいくつですか。
→ 答え：62（ホスト部が 6ビットなので 2^6 − 2 = 62 となるため）。

Q2. IP アドレスから MAC アドレスを求めるプロトコルは何ですか。
→ 答え：ARP（同一 LAN 内でフレームの宛先を決めるために使うため）。

Q3. 家庭内の複数の端末が1つのグローバル IP アドレスでインターネットに接続できるのは何の機能によりますか。
→ 答え：NAPT（ポート番号も変換して複数の通信を識別するため）。
