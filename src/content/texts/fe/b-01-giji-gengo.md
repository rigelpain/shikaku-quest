## この分野の位置づけ
科目Bは20問・100分で、16問が擬似言語のアルゴリズム問題です。合格基準は 600点/1000点なので、科目Bの成否は擬似言語をどれだけ正確に「手で動かせるか」で決まります。科目Aのアルゴリズム分野の知識が土台です。

## 要点
- 変数は「整数型: x」のように型と名前で宣言し、代入は「←」です。「=」は比較の等号です。
- 関数は「○整数型: 関数名(整数型: n)」のように定義し、戻り値は「return 値」で返します。
- 条件分岐は if (条件) 〜 elseif 〜 else 〜 endif、繰返しは while (条件) 〜 endwhile、for (i を 1 から n まで 1 ずつ増やす) 〜 endfor、do 〜 while (条件) の形です。
- 配列は「整数型の配列: a ← {3, 1, 4}」と書き、添字は原則 1 から始まります（問題文で 0 始まりと指定されることもあります）。
- 「÷」は整数の除算（小数点以下切捨て）、「mod」は剰余です。「a の要素数」のような日本語の関数表現も出ます。
- 空欄補充問題は、選択肢を当てはめて小さな入力でトレースし、期待される結果になるものを選びます。
- トレース表は「行・変数名ごとの値」の列を作り、1行実行するごとに変化した値だけを書き足します。
- 1問あたりの目安時間は約5分です。長い問題文は「関数の目的」「引数」「戻り値」を先に読み、処理の細部はトレースで追います。

## 頻出用語
- **大域変数** — 「大域: 整数型: cnt」と宣言され、どの関数からも参照・更新できる変数。
- **局所変数** — 関数の中で宣言され、その関数内だけで有効な変数。
- **引数** — 関数呼出し時に渡す値。
- **戻り値** — return で呼出し元に返す値。
- **要素数** — 配列の長さ。「a の要素数」と書かれる。
- **未定義** — 値が設定されていない状態を表す。「未定義の値」として出る。
- **and / or / not** — 論理演算子。and が or より優先される。
- **トレース** — 擬似コードを1行ずつ手で実行し変数の変化を追うこと。
- **空欄補充** — プログラム中の空欄に入る式や文を選ぶ出題形式。
- **再帰呼出し** — 関数が自分自身を呼ぶこと。呼出しごとに別の局所変数ができる。

## よくある引っかけ
- 「÷」の結果は切捨てです。7 ÷ 2 は 3、7 mod 2 は 1 です。負数が絡むときは問題文の定義を確認します。
- for の「1 から n まで」は n を含みます。「n − 1 まで」と書かれていたら含みません。終了条件の境界を必ず表に書きます。
- while は条件が真の間繰り返し、do〜while は最低1回は実行されます。最初から条件が偽の場合に差が出ます。
- 配列の添字が 1 始まりか 0 始まりかで答えが変わります。問題文の冒頭で確認します。
- 大域変数は関数を抜けても値が残ります。局所変数は毎回初期化されます。

トレースの例として、次の関数を sum(3) で呼び出してみます。

```text
○整数型: sum(整数型: n)
  整数型: total ← 0
  整数型: i
  for (i を 1 から n まで 1 ずつ増やす)
    total ← total + i
  endfor
  return total
```

| 行 | i | total |
|---|---|---|
| 初期化 | − | 0 |
| ループ1回目 | 1 | 1 |
| ループ2回目 | 2 | 3 |
| ループ3回目 | 3 | 6 |
| return | − | 6 |

## 確認クイズ
Q1. 擬似言語で「x ← 17 ÷ 5」を実行したあと、x の値はいくつですか。
→ 答え：3（÷ は整数の除算で小数点以下を切り捨てるため）。

Q2. 「for (i を 2 から 10 まで 2 ずつ増やす)」は何回繰り返しますか。
→ 答え：5回（i が 2, 4, 6, 8, 10 と変化し、10 を含むため）。

Q3. 繰返しの条件が最初から偽のとき、while と do〜while で実行回数はどう違いますか。
→ 答え：while は 0回、do〜while は 1回（do〜while は本体を実行してから条件を判定するため）。
